# 臺北 YouBike 空站觀察

115-1 地理資訊系統運用程式 HW4。用下拉選單選擇行政區：選「全部」可以比較某個時段各區的空站比例；選某一區可以看這個區在三個時段的空站比例、滿站比例與權重有車率。在「全部」畫面點某一區的長條，也可以直接切換到該區。

## App 用途

這個 App 可以觀察臺北各區 YouBike 在不同時段的使用狀況。資料是 2026-09-29（二）02:21（深夜）、09:40（上午）、12:41（中午）三個時段的快照。

假如我是使用者，可以選擇自己平常活動的區域，看這個區在不同時段的 YouBike 狀況：

- **空站比例**：有多少站「借不到」車。
- **滿站比例**：有多少站「還不了」車。
- **權重有車率**：整區的車「夠不夠」。

也可以比較同一區在不同時段的差別，進一步判斷某一區的車是「不夠」，還是「分配不均」。例如大安區 09:40 和 12:41 的權重有車率都是 0.332，但空站分別是 32 站和 8 站：整區的車量比例差不多，09:40 卻有比較多站借不到車，代表車子的分布比較不平均。

## 指標定義

| 指標 | 定義 |
|---|---|
| 空站 | 可借車 ≤ 門檻（預設 0，也就是可借車 = 0）。App 的滑桿可以調整門檻，**只影響空站比例** |
| 滿站 | 可還空位 = 0 |
| 空站比例 | 空站數 ÷ 營運中的站數（每站算 1，不分大小站） |
| 滿站比例 | 滿站數 ÷ 營運中的站數（每站算 1，不分大小站） |
| 權重有車率 | 該區 Σ可借 ÷ Σ可用格位（可借＋可還）；等於把每站有車率用可用格位數加權平均 |

資料處理的決策：

- **只算營運中的站**（`act = True`）。暫停營運的 27 站借不到也還不了，其中 24 站可借車為 0，算進分母會被當成空站，高估空站比例。
- **權重有車率的分母用可用格位，不用總停車格**（`Quantity`）。故障或停著不能借的車所占的格位，既借不到也還不了，算進分母會拉低有車率，把維修的問題混進來。
- **不用中位數代表各區可借車數**：車數是整數，中位數很容易並列，也看不出大站的數值；用可用格位當權重，就不必另外訂大站、小站的門檻。
- **臺大公館校區保留為獨立分區**：它是資料原始的 `sarea`，地址跨大安、中正區，要併入行政區需要空間連接（W6 再處理）。

## 限制

- 資料只有一天的三個瞬間快照，只能描述 2026-09-29 這三個時間點的狀況，不能推論其他日期或「每個星期二」都會這樣。
- 每個時段只是一個時間點（例如「上午」只代表 09:40 那一刻），不代表整段時間的平均。
- 時段標籤沿用 HW3 的決策：09:40 標成「上午」，不標成「通勤」。
- 各時段有 36%～46% 的站「總停車格 − 可借 − 可還」大於 0，原因可能是故障或保留的車位，但資料沒有說明，我不確定。

## 資料

| 項目 | 內容 |
|---|---|
| 來源 | 臺北市資料大平臺「YouBike2.0 臺北市公共自行車即時資訊」 |
| 網址 | `https://tcgbusfs.blob.core.windows.net/dotapp/youbike/v2/youbike_immediate.json` |
| 授權 | 政府資料開放授權條款－第 1 版（使用時須註明來源） |
| 資料時間 | 2026-09-29（二）02:21（深夜）、09:40（上午）、12:41（中午）三個時段的快照（`snapshot_time`，抓取時間） |
| 檔案 | `data/my_youbike_w3.csv`（HW3 清理後的資料，3 個時段 × 1808 站） |

`app.py` 需要的欄位：`時段`、`sno`、`sarea`、`act`、`available_rent_bikes`、`available_return_bikes`。其中 `act` 在 HW3 清理時已轉成 `True`／`False`（`True`＝營運中）。

## 在 Codespaces 執行

1. 在 repo 頁面按 **Code → Codespaces → Create codespace on main**。
2. 等環境建好（第一次約 2–3 分鐘，會自動安裝 `requirements.txt` 的套件）。
3. 在終端機輸入：

   ```bash
   solara run app.py
   ```

4. 右下角出現提示時，按 **Open in Browser**；或到「連接埠」分頁，開啟 8765 埠。
